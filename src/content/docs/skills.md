Навыки добавляет плагин AuraSkills. Навык растёт сам, когда вы занимаетесь его делом: копаете, рубите, сражаетесь, варите зелья. С каждым уровнем растут характеристики, открываются способности.

Навыки AuraSkills не связаны с [классом Fabled Roots](../classes/) и [профессиями](../jobs/). Все три системы качаются параллельно.

## Навыки

Названия даны так, как они переведены в игре. В скобках оригинал: он нужен для команд вида `/mining`.

| Навык | Как качать | Характеристика за каждый уровень | Характеристика за каждые 2 уровня |
|---|---|---|---|
| Фермер (Farming) | собирать урожай | Здоровье +0,4 | Сила +1 |
| Лесоруб (Foraging) | рубить деревья | Сила +1 | Стойкость +1 |
| Шахтер (Mining) | добывать камень и руды | Стойкость +1 | Удача +1 |
| Рыбак (Fishing) | ловить рыбу | Удача +1 | Здоровье +0,4 |
| Сельхоз (Excavation) | копать лопатой землю, песок, гравий | Регенерация +1 | Сила +1 |
| Лучник (Archery) | убивать мобов и игроков из лука | Критический шанс +1 | Сила +1 |
| Защитник (Defense) | получать урон от существ | Стойкость +1 | Здоровье +0,4 |
| Борец (Fighting) | убивать мобов оружием ближнего боя | Критический урон +1 | Регенерация +1 |
| Ловкость (Agility) | ходить, бегать, плавать, прыгать, падать | Регенерация +1 | Мудрость +1 |
| Алхимия (Alchemy) | варить зелья | Мудрость +1 | Здоровье +0,4 |
| Зачарователь (Enchanting) | зачаровывать, работать с наковальней и точилом | Мудрость +1 | Удача +1 |

Максимальный уровень каждого навыка 100. Точные источники опыта и сколько даёт каждый блок или моб: `/sk sources <навык>`.

## Опыт навыка

Опыт для следующего уровня считается по формуле `100 × (уровень − 2)² + 100`, где «уровень» тот, который вы получаете.

| Переход на уровень | Нужно опыта |
|---|---|
| 5 | 1 000 |
| 10 | 6 500 |
| 25 | 53 000 |
| 50 | 230 500 |
| 100 | 960 500 |

## Характеристики

| Характеристика | Что даёт |
|---|---|
| Сила | Урон от атаки оружием, рукой и из лука |
| Здоровье | Дополнительное здоровье |
| Регенерация | Скорость восстановления здоровья и маны |
| Удача | Шанс двойного дропа в навыках Фермер, Лесоруб, Шахтер, Рыбак и Сельхоз |
| Мудрость | Запас маны, получаемый опыт, скидка на наковальне |
| Стойкость | Снижение входящего урона |
| Критический шанс | Шанс нанести критический удар |
| Критический урон | Прибавка урона при критическом ударе, в процентах |
| Скорость | Скорость ходьбы и бега |

Свои характеристики: `/stats`.

## Способности

У каждого навыка пять пассивных способностей. Они открываются на уровнях навыка с 1 по 5 и улучшаются каждые 5 уровней. Пример для навыка Шахтер:

| Способность | Действие |
|---|---|
| Удачливый шахтер | Шахтерская удача, шанс дополнительного дропа |
| Шахтер | Больше опыта навыка |
| Мастер сбора | Больше урона киркой |
| Выносливый | Стойкость, пока в руке кирка |
| Закаленная броня | Шанс, что броня не потеряет прочность |

Полный список способностей с текущими значениями в меню `/skills`.

## Мана и мановые способности

Мана тратится на мановые способности. Запас маны 20 единиц плюс 2 за каждый уровень Мудрости. Мана восстанавливается сама, быстрее при высокой Регенерации. Текущая мана: `/mana`.

У восьми навыков есть мановая способность. Она открывается на 6-м уровне навыка и улучшается каждые 6 уровней. Стоимость и перезарядка ниже указаны для первого уровня способности.

| Навык | Способность | Как включить | Мана | Перезарядка |
|---|---|---|---|---|
| Фермер | Комбайнер: сам пересаживает урожай | ПКМ мотыгой, затем сломать урожай | 20 | 200 с |
| Лесоруб | Древовидный: валит дерево целиком | ПКМ топором, затем сломать дерево | 20 | 200 с |
| Шахтер | Быстрый Рудокоп: сильная Спешка | ПКМ киркой, затем копать | 20 | 200 с |
| Сельхоз | Терраформация: копает сразу несколько блоков вокруг | ПКМ лопатой, затем копать | 20 | 200 с |
| Рыбак | Острый крюк: урон тому, кого зацепила удочка | ЛКМ удочкой | 5 | 2 с |
| Лучник | Заряженный выстрел: стрела тратит ману и бьёт сильнее | ЛКМ луком переключает режим | 10 | нет |
| Защитник | Поглощатель: урон снимает ману вместо здоровья | ЛКМ щитом, затем получить урон | 10 | 200 с |
| Борец | Световой меч: быстрее скорость атаки | ПКМ оружием, затем ударить моба | 20 | 200 с |

С каждым уровнем мановой способности перезарядка короче, а стоимость выше.

## Команды

| Команда | Что делает |
|---|---|
| `/skills` | Меню навыков: уровни, прогресс, награды |
| `/stats` | Меню характеристик |
| `/mana` | Текущая мана |
| `/farming`, `/mining` и другие | Меню прогресса одного навыка, по английскому названию |
| `/sk sources <навык>` | Чем и сколько опыта даёт навык |
| `/sk top [навык]` | Таблица лидеров по всем навыкам или по одному |
| `/sk rank` | Ваше место в таблицах |
| `/abtoggle` | Выключить или включить строку прогресса навыков над панелью быстрого доступа |
| `/sk lang <язык>` | Язык сообщений и меню плагина только для вас |
| `/sk claimitems` | Забрать награды, которые не поместились в инвентарь |

Вместо `/sk` можно писать `/skills` или `/skill`.
