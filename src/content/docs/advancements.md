Датапак BlazeandCave's Advancements Pack (BACAP) добавляет больше 1000 достижений к ванильным. Их видно в обычном меню достижений, клавиша L.

## Вкладки

| Вкладка | О чём |
|---|---|
| BlazeandCave's Advancements | стартовые достижения и вехи: сколько достижений собрано в каждой вкладке |
| Mining | руды, добыча и всё, что из них делают |
| Building | крафт и строительство |
| Farming | посевы и растения |
| Animals | разведение, приручение, охота на животных, рыбалка |
| Monsters | враждебные мобы, отдельные испытания почти для каждого |
| Weaponry | оружие, обычное и необычное |
| Biomes | биомы, включая океан |
| Adventure | исследование, деревни, торговля, рейды, крупные структуры |
| Redstone | механизмы из редстоуна |
| Enchanting | зачарование |
| Statistics | статистика игрока |
| Nether | Незер, его мобы и структуры |
| Potions | зелья и эффекты |
| The End | Энд, его мобы и структуры |
| Super Challenges | самые сложные испытания. Вкладка открывается после победы над эндер-драконом |

## Награды

| Награда | Подробности |
|---|---|
| Опыт | за многие цели и испытания. Обычно 50–500 очков, за самые трудные до 3000 |
| Предметы | именные предметы-награды с описанием, за что получены |
| Трофеи | особые предметы с отметкой «Awarded for achieving» за испытания |

Все три вида наград включены. Получить награду можно один раз, вместе с достижением.

## Другие вкладки

Свои достижения есть и у других паков. Dungeons and Taverns добавляет вкладку о поиске таверн, данжей и победах над мини-боссами, например «Мастер подземелий». Vanilla Tweaks показывает свою вкладку со списком установленных улучшений.
