Профессии добавляет плагин Jobs Reborn. Профессия платит деньги за обычные действия: копать, рубить, охотиться, крафтить. Деньги идут на общий баланс, тот же, что в [экономике](../economy/).

Одновременно можно состоять максимум в 3 профессиях.

## Как начать

1. Откройте список: `/jobs browse`.
2. Вступите: `/jobs join <профессия>`, например `/jobs join Miner`.
3. Работайте как обычно. Выплата приходит за каждое засчитанное действие.

Посмотреть, за что платит профессия: `/jobs info <профессия>`. Названия профессий в командах пишутся на английском.

## Список профессий

Ставки ниже указаны для 1-го уровня, когда вы состоите в одной профессии. Первое число: деньги, второе: опыт профессии.

| Профессия | За что платит | Примеры ставок |
|---|---|---|
| Miner | добыча камня и руд, взрывы динамитом | камень 1 / 1, угольная руда 3 / 2, железная руда 3,5 / 2, алмазная руда 10 / 10, изумрудная руда 15 / 30 |
| Woodcutter | рубка брёвен | бревно 1 / 1, обтёсанное бревно 0,75 / 0,25 |
| Digger | земля, песок, гравий | земля 0,25 / 0,25, красный песок 1 / 1 |
| Farmer | сбор урожая, разведение, стрижка, дойка, приручение | спелая пшеница 1,5 / 3, разведение коровы 4 / 5, дойка коровы 5 / 5 |
| Hunter | убийство мобов и приручение | зомби 10 / 15, крипер 15 / 15, визер 50 / 120, эндер-дракон 2000 / 2000 |
| Fisherman | рыбалка | треска 15 / 15, лосось 20 / 25, иглобрюх 25 / 25 |
| Builder | установка блоков | камень 1,3 / 2 |
| Crafter | крафт предметов | раздатчик 4 / 4, палка 0,1 / 0,1 |
| Weaponsmith | крафт, ремонт и переплавка оружия и брони | алмаз из руды в печи 7 / 20 |
| Enchanter | зачарование предметов | алмазный меч 9 / 30 |
| Brewer | варка зелий, ставка зависит от ингредиента | незерский нарост 6 / 6, огненный порошок 12 / 12, слеза гаста 22 / 22, дыхание дракона 25 / 25 |
| Explorer | исследование новых чанков, работа кистью | первый посетивший чанк 5 / 5, второй 2,5 / 2,5, третий 1 / 1; подозрительный гравий 6 / 6 |

За убийство игрока платят Builder, Crafter, Digger, Explorer, Farmer, Fisherman, Miner и Woodcutter, по 7,5. Hunter платит 9.

Некоторые действия штрафуют. Miner теряет деньги, если ставит руду обратно: так нельзя заработать, ставя и снова добывая один блок.

## Уровни и доход

| Параметр | Значение |
|---|---|
| Максимальный уровень | 200 |
| Опыт до следующего уровня | `10 × уровень + 4 × уровень²` |
| Рост дохода | +1% к ставке за каждый уровень выше первого |
| Штраф за несколько профессий | −5% к ставке за каждую профессию сверх первой |

Пример: на 21-м уровне профессии ставка выше на 20%. Если вы при этом состоите в трёх профессиях, из неё вычитается 10%.

Кроме денег и опыта профессии, за работу начисляются очки Jobs. Их тратят в магазине `/jobs shop`.

## Ежедневные задания

У профессий есть ежедневные задания. Например, у Woodcutter: срубить по 50 дубовых, берёзовых брёвен и брёвен джунглевого дерева. Список: `/jobs quests`. Задания обновляются раз в сутки.

## Команды

| Команда | Что делает |
|---|---|
| `/jobs browse` | Список профессий |
| `/jobs join <профессия>` | Вступить в профессию |
| `/jobs leave <профессия>` | Уйти из профессии |
| `/jobs leaveall` | Уйти из всех профессий |
| `/jobs info <профессия>` | За что платит профессия |
| `/jobs stats` | Ваши уровни |
| `/jobs top <профессия>` | Лучшие игроки профессии |
| `/jobs gtop` | Лучшие игроки по всем профессиям |
| `/jobs points` | Ваши очки Jobs |
| `/jobs shop` | Магазин за очки |
| `/jobs quests` | Ежедневные задания |
| `/jobs limit` | Лимит выплат |
| `/jobs bonus <профессия>` | Действующие бонусы |
| `/jobs toggle actionbar` | Показывать или скрыть выплаты над панелью быстрого доступа |
| `/jobs blockinfo` | Сведения о блоке, на который вы смотрите |
| `/jobs iteminfo` | Сведения о предмете в руке |
| `/jobs explored` | Кто уже посещал этот чанк |

> [!NOTE]
> Ставки и лимиты указаны по стандартным настройкам плагина и могут меняться.
