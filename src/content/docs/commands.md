В угловых скобках обязательные значения, в квадратных необязательные. Скобки писать не нужно: `/pay Steve 100`.

> [!NOTE]
> Команды EssentialsX (телепорты, дом, чат, баланс) выдаются через ранги. Если команда отвечает, что у вас нет прав, значит она пока не открыта для вашего ранга.

## Аккаунт

| Команда | Что делает |
|---|---|
| `/register <пароль> <пароль>` | Регистрация при первом входе |
| `/login <пароль>` | Вход в аккаунт. Коротко: `/l` |
| `/changepassword <старый> <новый>` | Сменить пароль |
| `/logout` | Выйти из аккаунта, не отключаясь |
| `/skin set <ник>` | Поставить скин игрока с этим ником |
| `/skin clear` | Сбросить скин |
| `/skins` | Меню скинов |

## Меню и перемещение

| Команда | Что делает |
|---|---|
| `/menu` | Главное меню сервера |
| `/spawn` | Точка появления |
| `/sethome [название]` | Поставить дом |
| `/home [название]` | Телепорт домой. Если домов несколько, без названия покажет список |
| `/delhome <название>` | Удалить дом |
| `/back` | Вернуться на место до телепорта |
| `/warp [название]` | Список варпов или телепорт на варп |
| `/tpa <игрок>` | Попросить разрешения телепортироваться к игроку |
| `/tpahere <игрок>` | Позвать игрока к себе |
| `/tpaccept` | Принять запрос на телепорт |
| `/tpdeny` | Отклонить запрос |
| `/tpacancel` | Отменить свой запрос |
| `/kit [набор]` | Список наборов или получить набор |

## Экономика

| Команда | Что делает |
|---|---|
| `/bal [игрок]` | Баланс |
| `/baltop` | Самые богатые игроки |
| `/pay <игрок> <сумма>` | Перевести деньги |
| `/paytoggle` | Запретить или разрешить переводы вам |
| `/shop` | Магазин |
| `/sellall` | Продать всё, что принимает магазин |
| `/sellall hand` | Продать предметы как в руке |

Подробно: [Экономика](../economy/).

## Общение

| Команда | Что делает |
|---|---|
| `/msg <игрок> <текст>` | Личное сообщение. Также `/m`, `/w`, `/tell` |
| `/r <текст>` | Ответить на последнее личное сообщение |
| `/mail send <игрок> <текст>` | Письмо игроку, который сейчас не в сети |
| `/mail read` | Прочитать письма |
| `/ignore <игрок>` | Не получать сообщения от игрока. Повторно: снять игнор |
| `/afk` | Отметить, что вы отошли |
| `/list` | Кто в сети |
| `/helpop <текст>` | Написать администрации |

## Команды датапаков

Эти команды работают через `/trigger` и доступны всем.

| Команда | Что делает |
|---|---|
| `/trigger Trims_Menu.BLUE` | Меню сил отделки брони |
| `/trigger duraPing` | Настройка предупреждения о прочности |
| `/trigger nc_inOverworld` | Координаты парного портала в Незере |
| `/trigger nc_inNether` | Координаты парного портала в обычном мире |
| `/trigger as_help` | Справка по настройке стоек для брони |

Меню Fabled Roots открывается из меню паузы: Esc → «Пользовательские настройки...» → Fabled Roots. Подробно: [Расы](../races/).
